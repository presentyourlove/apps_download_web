# 1. Record architecture decisions

Date: 2026-01-23

## Status

Accepted

## Context

We need to record architecture decisions to maintain a history of the software design and facilitate onboarding of new developers.

## Decision

We will use Architecture Decision Records (ADRs) to document significant architectural decisions.
We will use the [MADR](https://adr.github.io/madr/) template.

## Consequences

### Positive

- Clear history of decisions.
- Context for future developers.

### Negative

- Slight overhead in documentation.
